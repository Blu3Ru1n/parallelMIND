# InfiniteNotes Sample

This is a simplified SwiftUI sample demonstrating an infinitely nestable folder structure for notes. Each note may contain a mix of attachments including text, images, audio, video, generic files, and annotated images.

The example uses `NavigationSplitView` for a sidebar-driven layout similar to Asana while keeping interactions lightweight like Google Keep.

> **Note:** This sample focuses on data models and view structure. Media capture, persistence, and annotation tools would require additional implementation and the appropriate iOS frameworks.
